## AI

- [Hugging Face Papers — S-Mind: Internalizing Multi-View Geometry for Spatial Intelligence](https://huggingface.co/papers/2611.28649) — builds 3D scene understanding into a multimodal language model via learned "spatial tokens" that fuse multiple camera views, letting it reason spatially without external tools and run about 100x faster than a tool-based agent.
- [Hugging Face Papers — Rewirable Circuits in Transformers with Loom Attention](https://huggingface.co/papers/2611.30634) — proposes "loom attention," where each attention head picks, per token, which earlier heads' outputs to read from; the resulting LoomFormer matches Transformers trained with over 3x the compute while adding only about 2-3.7% FLOPs.
- [Hugging Face Papers — CUA-SEE: Self-Evolving Evaluation Environments for Computer-Use Agents](https://huggingface.co/papers/2611.30962) — proposes a closed-loop eval framework that co-evolves tasks, probes, and verifiers from an agent's own rollouts, so benchmarks keep raising difficulty and precision as computer-use agents improve instead of saturating.
- [Hugging Face Papers — Coding4Games: Can Modern Coding Agents Play Modern Video Games?](https://huggingface.co/papers/2611.31974) — coding agents that write standalone, no-LLM-at-runtime game-playing programs from screen pixels beat the strongest GUI-agent baseline on 13 of 15 modern games.
