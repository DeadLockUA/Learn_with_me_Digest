## Development

- [InfoQ](https://www.infoq.com/news/2026/10/google-wrong-flagging/) — Google's automated ad-safety system flagged RACE, an open-source Rust macOS terminal multiplexer, as malware and suspended the developer's ad account despite Apple notarization and clean scans, reversing only after public escalation.
- [InfoQ](https://www.infoq.com/news/2026/10/cloudflare-cf-cli/) — Cloudflare launched the open-source `cf` CLI in beta to replace Wrangler, built agent-first with JSON output by default and covering 3,000+ API operations versus Wrangler's roughly 280.

## AI

- [OpenAI Research](https://openai.com/index/eu-text-provenance/) — OpenAI is rolling out "textGrain," a statistical text-watermarking scheme for EU AI Act compliance: opt-in for API customers worldwide, on by default for eligible ChatGPT/Codex text generated in the EU, with a detector limited to approved researchers and a claimed ~80% detection rate on 200-token passages (~95% on 400-token) at a 1% false-positive rate.
- [arXiv cs.CL](https://arxiv.org/abs/2610.06829) — CLIFT claims state-of-the-art results among open-source web agents on WebArena Infinity, using conformal self-verification to enable judge-free test-time scaling without a separate reward model.
