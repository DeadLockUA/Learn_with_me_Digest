## AI

- [Agent Trust Infrastructure (ATI)](https://arxiv.org/abs/2611.23202) — proposes a federated architecture letting autonomous agents from different organizations verify each other's identity, configuration integrity, and authorization via peer certificate authorities instead of a shared root; a simulated evaluation raised attack containment from 43% to 84% at roughly 174 microseconds of overhead per request.
- [Done, But Still Working: Anytime Evaluation of When Coding Agents Should Stop](https://arxiv.org/abs/2611.22901) — replaying ~6,000 recorded SWE-bench Verified runs across eight open models finds that stopping coding agents at the first passing self-test could save anywhere from under 1% to 57% of cost depending on model and scaffold, though whether patch quality holds isn't established.
- [Values Shape What Self-Improving Coding Agents Build](https://arxiv.org/abs/2611.23067) — a short value statement in a coding agent's persistent instruction file changes both its performance and the shape of what it builds: openness-to-change values improved results, conservation values scored below having no values at all, and letting the agent revise its own values narrowed those differences.
