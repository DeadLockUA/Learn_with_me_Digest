## AI

- [Compaction, decay and reinforcement in a two-tier conversational memory: a paired evaluation against retrieval-augmented generation](https://arxiv.org/abs/2611.09807) — on 1,985 LoCoMo questions, compaction-based memory beats RAG by 6.8 points (71.4% vs 64.6%, p=5.5e-08) using 34% fewer prompt tokens on non-adversarial questions, but the lead shrinks to a non-significant 2.0 points once an adversarial category is included, where RAG leads by 14.6 points.
- [MemoryDojo: Benchmarking Poisoning Through LLM Agent Memory](https://arxiv.org/abs/2611.09721) — a new benchmark of 155 multi-session trajectories across four domains finds every one of five tested agent-memory systems is vulnerable to a malicious instruction planted in one session and later acted on, with how much it matters varying by system design.
- [From Procedures to Permissions: Learning Precise Subagent Authorization from Agent Skills](https://arxiv.org/abs/2611.08905) — training on procedures mined from Agent Skills lifts a Qwen3.5-35B-A3B subagent's tool-permission precision by 13.4 points, workspace-permission precision by 24.1 points, and task success by 11.6 points on ClawArena-Team.
- [The Last Mile to the Real World: Agent-Native Primitives as Reusable Building Blocks for Solving Real-World Tasks](https://arxiv.org/abs/2611.07461) — pairing frontier coding agents with reusable "agent-native primitives" (HEELO) raises Terminal-Bench 4.0 resolution from 37.3% to 55.5% on the same backbone, and on 46 real-world tasks takes Claude Opus 5.5 with Claude Code from 9 solved tasks alone to 39 when connected via HEELO's MCP server, at 1.9x less time and 1.55x lower cost per completed task.
- [How Much Conversation History Does an AI Agent Need?](https://arxiv.org/abs/2611.09662) — testing fixed context budgets on 1,100 questions, the authors find the score gain per added token shrinks at the largest budgets tested, and which message-retention strategy best matches the full conversation depends on the model and on whether the answer needs an exact earlier reference (unverified: the paper reports no specific score values for this).
- [Hide your slop PR descriptions behind `<details><summary>`](https://simonwillison.net/2026/Nov/9/details-summary/) — Simon Willison argues PRs are his real unit of work, and since coding agents already write usable PR descriptions, the fix for noisy ones is collapsing them behind a `<details><summary>` toggle rather than discarding them.
- [Simon Willison ports a Three.js scene to vanilla WebGL with Claude Opus 5.5](https://news.ycombinator.com/item?id=50416456#50421091) — the port shows Opus 5.5 can produce working 3D rendering code without the Three.js library, though Willison still finds the Three.js version easier to read.
