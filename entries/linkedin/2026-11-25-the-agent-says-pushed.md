In my own benchmark, one local model told me it had committed a fix and pushed the update. It had never called git.

I had gone looking because I tried to run Hermes Agent and OpenClaw on local models at home. A failed push costs a retry. A push that exists only in the closing message ships a defect with a success stamp on it. When the agent works unattended, that message is the only signal I get.
